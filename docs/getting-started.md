# FirstCut(퍼스트컷) 시작 가이드

클로드(Claude)와 영상 편집 프로그램을 처음 쓰는 분을 위한 안내서입니다.
FirstCut은 **영상의 지루한 초벌 편집(NG 자르기, 무음 지우기, 테이크 고르기, 말버릇 정리)을 클로드에게 맡기고**, 여러분은 편집 프로그램에서 마무리만 하도록 도와줍니다.

터미널을 몰라도 됩니다. 설치할 때 한 줄 복사해 붙여넣는 것이 전부이고, 그 뒤로는 클로드와 대화만 하면 됩니다.

---

## 이게 뭐 하는 도구인가요?

1. 클로드가 영상의 **대사를 직접 받아써서 내용을 읽고**, 남길 부분과 지울 부분을 판단합니다.
2. 중요한 결정은 **보기를 주고 고르게 합니다.** 마음대로 자르지 않습니다.
3. 결과를 **프리미어 프로 또는 파이널컷 프로의 타임라인**으로 만들어, 프로그램을 열고 띄우는 것까지 해줍니다.

특징 세 가지:

- **영상을 새로 만들지 않습니다.** 원본은 그대로 있고, "어디를 어떻게 잘랐는지"라는 설계도만 넘어갑니다.
- **되돌릴 수 있습니다.** 편집 프로그램에서 컷 경계를 잡아 늘리면 잘린 부분이 다시 나타납니다.
- **영상이 어디로 업로드되지 않습니다.** 클로드가 읽는 것은 대사 텍스트뿐입니다.

---

## 준비물

| 준비물 | 설명 |
|---|---|
| 클로드 코드 | 여러분 컴퓨터에서 직접 일하는 클로드. [여기서 설치](https://claude.com/claude-code) |
| 편집 프로그램 | 프리미어 프로 또는 파이널컷 프로 |
| 촬영본 폴더 | 영상 파일들이 든 폴더. 여러 개여도 됩니다 |

## 설치 (처음 한 번, 한 줄)

터미널을 엽니다. 맥이라면 화면 오른쪽 위 돋보기(Spotlight)를 누르고 "터미널"이라고 검색하면 나옵니다. 열리면 아래 한 줄을 복사해 붙여넣고 엔터:

```bash
curl -fsSL https://raw.githubusercontent.com/yezji/claude-firstcut/main/install.sh | bash
```

"✅ 설치가 끝났습니다!"가 나오면 터미널은 닫아도 됩니다. 이후로 터미널을 쓸 일은 없습니다.

## 사용법: 대화 한 번이면 됩니다

클로드 코드를 열고 아래를 입력하세요. (슬래시까지 그대로)

```
/firstcut
```

그 다음은 클로드가 순서대로 물어봅니다. 실제 흐름을 미리 보여드릴게요.

### ① 폴더 알려주기

> 클로드: 영상이 든 폴더를 Finder에서 이 창으로 끌어다 놓으세요. 경로가 자동으로 입력돼요.

폴더를 끌어다 놓으면, 클로드가 안의 영상들을 읽고 목록을 보여줍니다. "이 5개가 맞나요? 빼실 파일 있나요?" — B롤이나 테스트 촬영이 섞여 있으면 이때 빼면 됩니다.

### ② 보기 고르기 (두 가지)

**말버릇 정리 강도** — 말버릇("어…", "음", "그니까") 정리는 기본으로 해주고, 얼마나 할지만 고릅니다.

> **1. 순한맛** — 문장 사이 긴 필러만. 말투가 자연스럽게 남음 (브이로그, 인터뷰)
> **2. 보통** — 반복 말버릇("이게, 이게 뭐냐면")까지 정리 (대부분의 유튜브 영상)
> **3. 매운맛** — 문장 중간 "어"까지 싹. 밀도 최고, 점프컷 느낌 (정보 전달형, 숏폼)

**완성본 분량**

> **1. 다듬기만** — NG·무음·말버릇만 지우고 내용은 전부
> **2. 절반쯤 압축** — 곁가지를 정리
> **3. 시간 지정** — "3분"처럼 알려주기
> **4. 숏폼** — 60초 안쪽, 핵심만

번호로 답해도 되고 "보통으로, 3분 정도"처럼 말해도 됩니다.

### ③ 내용 보고 받고 방향 정하기

클로드가 대사를 다 받아쓰고 나면, **영상에 뭐가 들어있는지 알게 된 상태**로 이렇게 보고합니다.

> 클로드: 전사해 보니 이런 구성이에요 (원본 12분):
> ① 인사와 근황 (1분 30초) ② 주제 소개 (3분) ③ 직접 겪은 에피소드 (2분 30초) ④ 핵심 정리와 팁 (3분) ⑤ 마무리 (2분)
>
> 3분 목표면 ②④가 뼈대예요. ③ 에피소드는 시간상 빼는 게 맞는데, 제일 사람 냄새 나는 부분이라 아깝긴 해요. 어떻게 할까요?
> **1. 추천대로** / **2. ③도 살리기** / **3. 직접 고르기**

여러분은 번호만 고르면 됩니다. 그래도 헷갈리는 세부 구간(같은 말을 두 번 했는데 어느 쪽이 나은지 등)은 한 번 더 모아서 물어봅니다.

### ④ 완성 — 편집 프로그램이 저절로 열립니다

클로드가 타임라인 파일을 만들고, 편집 프로그램을 열어 불러오는 것까지 해줍니다.

- **파이널컷**: 파이널컷이 열리고 가져오기 확인 창이 뜹니다. 확인만 누르면 끝.
- **프리미어**: 연동(MCP)이 설정돼 있으면 자동으로 들어가고, 아니면 클로드가 키 입력으로 가져오기를 대신하거나 "Ctrl+I 한 번만 눌러주세요"라고 안내합니다.

영상 위치를 클로드가 이미 알고 있어서, "미디어 오프라인" 같은 빨간 화면 없이 바로 재생됩니다.

---

## 편집 프로그램에서 마무리하기

타임라인을 보면 두 층이 있습니다.

- **아래층** — 클로드가 확정한 편집본. 재생하면 이게 나옵니다.
- **위층의 반투명 클립들** — "이건 직접 보고 정하세요"라며 올려 둔 **보류 후보**. 꺼져 있어서 재생에 안 섞입니다. 이름에 이유가 적혀 있습니다. 예: `[keep?] 애드립 - 흐름 자연스러움`

후보를 하나씩 재생해 보고:
- **살리기** → 클립을 켜고(프리미어: 우클릭 → 사용 / 파이널컷: V키) 아래층에 끼워 넣기
- **버리기** → Delete

후보 정리가 끝나면 클로드 코드에서 **`/firstcut-subs`**를 입력하세요. 살린 후보가 있는지 물어본 뒤, 편집본 시간에 딱 맞는 최종 자막 파일을 만들어 줍니다. 음악과 자막을 얹고 내보내면 완성입니다.

---

## 클로드 웹/앱에서 쓰는 방법 (수동)

클로드 코드 없이 claude.ai나 클로드 앱에서도 쓸 수 있습니다. 이 경우 몇 가지를 직접 합니다.

1. 스킬 파일을 대화에 올리고 Save skill로 설치
2. 영상(또는 편집 프로그램 받아쓰기로 만든 srt)을 대화에 첨부하고 `/firstcut` 입력
3. 질문 답하기는 동일
4. 완성된 타임라인 파일(XML)을 다운로드해서 편집 프로그램에서 직접 가져오기(Ctrl+I), 미디어 연결

전 과정 자동을 원하면 클로드 코드를 권합니다.

## 자주 묻는 질문

**원본이 망가질 수 있나요?**
아니요. 원본 파일은 단 1초도 수정되지 않습니다. 잘못 잘려도 편집 프로그램에서 컷 경계를 당기면 되살아납니다.

**영상 파일이 여러 개인데요?**
폴더째 주면 됩니다. 이어지는 파트인지, 같은 내용을 여러 번 찍은 건지 물어본 뒤, 파일을 넘나들며 좋은 부분만 골라 하나로 엮습니다. 경쟁하는 테이크는 위아래로 나란히 놓아서 비교하며 고를 수 있습니다.

**자막도 만들어 주나요?**
네, 두 번요. 받아쓴 자막(원본 기준)을 먼저 주고, 컷 확정 후 `/firstcut-subs`를 입력하면 편집본에 딱 맞는 최종 자막을 만들어 줍니다.

**받아쓰기가 안 된다고 해요.**
음성 인식 모델 다운로드가 막힌 환경일 수 있습니다. 클로드가 해결 방법 두 가지를 안내해 줍니다: 네트워크 설정에 주소 하나 추가하기, 또는 편집 프로그램의 받아쓰기로 만든 srt 주기.

**완성 영상(mp4)을 주는 게 아닌가요?**
네, 일부러요. 초벌컷은 기계가, 최종 판단과 감각적인 마무리는 사람이 하는 게 결과물이 좋습니다. 내보내기는 편집 프로그램에서 하면 됩니다.

**수정하고 싶으면요?**
"2분 31초 애드립 살려줘"라고 말하면 됩니다. 처음부터 다시 분석하지 않고 그 부분만 고쳐서 타임라인을 새로 만듭니다.

## 한눈에 보는 전체 흐름

```
설치 한 줄 (처음 한 번)
        ↓
/firstcut 입력
        ↓
폴더 끌어다 놓기 → 말버릇 강도·분량 고르기
        ↓
클로드가 받아쓰기 → 내용 구성 보고 → 살릴 것 고르기
        ↓
편집 프로그램이 열리고 타임라인 완성 (미디어 연결까지 자동)
        ↓
보류 후보만 보고 결정 → /firstcut-subs로 완성본 자막 받기
        ↓
음악 얹고 내보내기 — 완성!
```
